# Chronicles Engine — Sprint 1

Prima fondazione modulare senza rompere il prototipo funzionante.

## Incluso
- Campaign Engine con schema v3 e migrazione automatica dei salvataggi v1/v2.
- Save Engine: save/load/export/import API.
- Universe Loader con catalogo dei cinque universi.
- Manifest iniziali per Age of Legends, Shadows Beyond, Genesis, Neon Protocol e Fractured Domains.
- PWA esistente ancora funzionante e collegata al Master AI.

## Upload
Caricare l'intero contenuto dello ZIP nella root del repository `chronicles`, mantenendo le cartelle.
