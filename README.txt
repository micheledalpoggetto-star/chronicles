CHRONICLES — PWA iPHONE

1. Pubblica questa cartella su un hosting HTTPS statico (GitHub Pages, Netlify, Cloudflare Pages, ecc.).
2. Apri l'indirizzo in Safari su iPhone.
3. Tocca Condividi → Aggiungi alla schermata Home.
4. Apri Chronicles dalla Home.
5. In gioco: scrivi l'azione → Al Master → Condividi al Master.
   Se ChatGPT compare nel foglio condivisione iOS, selezionalo.
   Altrimenti usa Copia + Apri ChatGPT.
6. Incolla nell'app il JSON restituito dal Master e premi Applica.

Non usa API OpenAI e non comporta costi API.
Dopo il primo caricamento, il service worker permette l'uso offline dell'interfaccia.
